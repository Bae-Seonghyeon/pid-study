배양 설비 통합 P&ID

배양 설비 P&ID와 운전 시나리오

두 개의 도면을 탭으로 나눴습니다. 생산용 SUB 공정 P&ID는 실제 설비에 가깝게 그린 교육용 도면이고, 5L 벤치탑 배양기는 실습 강의 자료를 바탕으로 포트 구성과 조립부터 정리까지의 운전 순서를 담았습니다. 기기를 누르면 태그 약자 풀이와 역할, 조작 결과가 나오고, 시나리오를 고르면 단계별로 강조됩니다. 도면 아래 약자 풀이 표에는 도면에 나오는 모든 약자를 정리했습니다.

시나리오

약자 풀이

파란 글자가 약자를 이루는 글자입니다. 약자를 누르면 도면에서 해당 기기가 표시됩니다. 태그의 숫자는 설비 일련번호나 제어 루프 번호이고, 같은 번호의 계기는 한 루프로 묶입니다(PT-160이 재고 PIC-160이 제어). 설비 약자는 회사마다 조금씩 다르며, 이 도면의 태그는 교육용으로 지은 것입니다.

선의 의미

  • 청정 공기, 공정 가스
  • 청정 스팀
  • 냉각수, 재킷 순환수, 세척수
  • 배지, 배양액 (스테인리스 배관)
  • 일회용 튜브
  • 배기 (각 필터에서 대기로)
  • 계기 신호
  • 시나리오에서 활성화된 신호와 흐름
